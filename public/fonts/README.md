# Portfolio fonts

Geist, Geist Mono, and Fraunces Latin variable font files are the same Google Fonts assets used by the original template, preserved from its local Next.js font cache. They are served locally to keep builds independent of Google Fonts requests.

Sources: https://fonts.google.com/specimen/Geist, https://fonts.google.com/specimen/Geist+Mono, https://fonts.google.com/specimen/Fraunces.

Outfit Regular (400) is served locally for titles and headings. Geist remains the body and UI font.

Official source: https://fonts.google.com/specimen/Outfit
License: SIL Open Font License 1.1, included in outfit-OFL.txt.
Font file downloaded from the official Google Fonts CDN.
